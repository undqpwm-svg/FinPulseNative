# ФинПульс — мобильное приложение руководителя

Кликабельный макет приложения для руководителя к расширению «ФинПульс» для 1С:Бухгалтерии для Казахстана 3.0: деньги на сегодня, платёжный календарь с кассовыми разрывами, согласование заявок на оплату, отчёты и уведомления.

Два режима:
- **настоящий** (по умолчанию) — вход через Telegram-бота SmartSol, данные из 1С через сервер-посредник `api.smartsol.pro`.
  Сервер ещё не подключён: вход в этом режиме пока отвечает «Нет связи с сервером»;
- **демо** — для показов: сервера нет, все организации, люди и суммы **выдуманы**, совпадения случайны.

**Открыть:** https://finpulse.smartsol.pro/ · **сразу демо:** https://finpulse.smartsol.pro/#/demo

## Как открыть

- **На компьютере** — откройте ссылку: макет показывается по центру в рамке телефона, рядом QR-код для телефона.
- **На телефоне** — откройте ссылку или наведите камеру на QR-код.
- Демо: на экране входа «Посмотреть демо» (или адрес `#/demo`) → «Войти через Telegram» → в шторке «бота» нажать «Поделиться номером», затем нажать на код (он скопируется) → в приложении «Вставить код».
  Выход из демо — «Профиль» → «Выйти из демо».

## Установка на телефон

**iPhone (Safari):** открыть ссылку → кнопка «Поделиться» → «На экран Домой» → «Добавить». Приложение откроется без адресной строки.

**Android (Chrome):** открыть ссылку → меню ⋮ → «Добавить на главный экран» (или «Установить приложение»).

## Экраны

1. Вход через Telegram: бот присылает одноразовый код из 6 цифр → ввод кода в приложении (ошибки: неверный код с числом оставшихся попыток, вход отклонён, блокировка 15 минут, срок вышел, доступ выключен, нет связи с учётом).
2. Выбор организации: три ТОО с мини-сводкой.
3. Главная: деньги на сегодня (банк, касса), прогноз остатка, кассовый разрыв, заявки на согласовании, 7 дней, дебиторка.
4. Платёжный календарь: неделя и месяц, остаток на начало дня, красные дни разрыва, платежи и поступления по дню.
5. Заявки: список, карточка (бюджет и лимит, влияние на остаток, комментарий, счёт PDF, маршрут), «Согласовать» / «Отклонить» с обязательным комментарием.
6. Отчёты: ДДС по неделям, план-факт по статьям, топ-5 должников.
7. Уведомления: оплаты, новые заявки, разрыв, утренняя сводка.
8. Профиль: организации, настройки уведомлений, «Сбросить демо», «Выйти».

Решения по заявкам сохраняются в браузере (localStorage). Вернуть исходное состояние: **Профиль → Сбросить демо**.

## Как поменять цифры

Все данные лежат в одном файле [`docs/data/demo.json`](docs/data/demo.json):

- `today` — «сегодняшняя» дата демо (`"2026-11-11"`); `null` — брать реальную дату;
- даты платежей, заявок и уведомлений заданы смещением `d` от `today` (0 — сегодня, 1 — завтра, −1 — вчера);
- остатки на начало дня и кассовые разрывы считаются автоматически из `accounts` и `flows`;
- у каждой организации свои `accounts`, `flows`, `requests`, `debtors`, `reports`, `notifications`.

После правки — закоммитить в ветку, через минуту сайт обновится.

## Устройство

Статический сайт без сборки: HTML, CSS, JS-модули в папке `docs/`, хеш-роутинг (`#/calendar`, `#/requests/r101` …) — обновление страницы на любом экране не даёт 404. PWA: `manifest.webmanifest`, иконки, `sw.js` (оболочка — сначала сеть, без сети — кэш; ответы API не кэшируются; push). Шрифты Geologica и Onest из Google Fonts.

Экраны берут данные только через клиент API (`docs/js/api/`): реализация «демо» читает `data/demo.json`, «сервер» — ходит
в API. Режим по умолчанию и адрес API — в `docs/js/config.js`. Что приложение ждёт от API — [`spec/api-client.md`](spec/api-client.md).
Секретов в коде нет: адрес API — в конфиге, токен сессии — только в браузере.

```
docs/
  index.html             оболочка, рамка телефона для компьютера
  css/app.css            стили (фирменные цвета SmartSol)
  js/config.js           адрес API, режим по умолчанию, таймауты
  js/app.js              роутер, загрузка экранов, ошибки, переходы, нижняя навигация
  js/screens.js          экраны и действия (данные — только через api.*)
  js/api/index.js        клиент API: переключение демо / сервер
  js/api/server.js       запросы к api.smartsol.pro, токен сессии, ошибки
  js/api/demo.js         демо-реализация на data/demo.json
  js/push.js             разрешение и подписка web push
  js/store.js            расчёты демо: остатки, разрывы, заявки, уведомления
  js/util.js             формат сумм и дат по-русски
  data/demo.json         демо-данные
spec/api-client.md       что приложение ждёт от API (черновик до контракта)
tests/e2e.cjs            демо в Playwright (iPhone 13 + десктоп)
tests/server-mock.cjs    режим «сервер» на подменённых ответах API
screenshots/             скриншоты экранов демо; screenshots/server — состояния режима «сервер»
```

## Проверка

```bash
node tests/e2e.cjs                 # локально, поднимает свой сервер
node tests/e2e.cjs --shots         # + обновить скриншоты в /screenshots
node tests/e2e.cjs https://finpulse.smartsol.pro/   # опубликованный сайт
node tests/server-mock.cjs         # вход, ошибки, «1С недоступна», согласование, push — без сервера
```

Нужен Node.js 18+ и Playwright (`npm i -D playwright && npx playwright install chromium`).

## Публикация на GitHub Pages

Папка `/docs` публикуется целиком — документацию и заметки туда не кладём (только в `spec/` и README).

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → ветка `claude/finpuls-mobile-demo-8vmvc5`, папка **/docs** → Save. Свой домен: файл `docs/CNAME` (`finpulse.smartsol.pro`), DNS: CNAME `finpulse.smartsol.pro` → `undqpwm-svg.github.io`, в настройках Pages — Custom domain и Enforce HTTPS. Все пути в приложении относительные, поэтому сайт работает в корне домена без пересборки.
